How the analysis works

01

TF-IDF vectorization

preprocessing

Turns every sentence into numbers before any model can use it. Each word is scored by how often it appears in that sentence versus how common it is everywhere else, so filler words like "the" or "is" score low and distinctive words score high. Stop words are removed, only single words are used as features, and the vectorizer keeps the 150 most informative words overall.

02

SVM — Support Vector Machine

classification

The model that actually decides STRONG vs. WEAK. It finds the dividing line that best separates strong sentences from weak ones in TF-IDF space, choosing the widest possible gap between the two groups. A linear kernel is used because it performs well on sparse text data and stays interpretable: it's essentially learning which words push a sentence toward "strong" and which push it toward "weak."

03

KNN — K-Nearest Neighbors

comparison only

Trained on the same data as the SVM, but works differently: to classify a sentence it finds the 3 most similar training sentences and takes a majority vote of their labels. It isn't used to serve real predictions — it's trained purely so its accuracy can be compared against the SVM's.

04

SVR — Support Vector Regression

scoring

A STRONG/WEAK label alone is coarse, since two very different sentences can both be labelled "strong." SVR predicts a continuous 0–1 strength score instead of a category, which is what powers the strength bar next to every sentence and lets two "strong" sentences still be ranked against each other.

05

K-Means clustering

theming

The only model that never sees the strong/weak labels. Given the sentences in your submitted text, it groups them by how similar their wording is, and each group is labelled with its most distinctive word. This is what produces the theme tag shown on every sentence, useful for spotting which parts of a passage are really talking about the same idea.

06

5-fold cross-validation

evaluation

With only 50 labelled training sentences, a single train/test split would be unreliable. Instead the data is split into 5 groups; each model trains on 4 and is tested on the 5th, five times over, so every sentence gets tested exactly once. The 5 resulting scores are averaged into the accuracy numbers shown above.

The model trains once when the server starts, on a fixed set of 50 hand-labelled sentences. Text you submit is only ever analyzed — it never retrains the model.
